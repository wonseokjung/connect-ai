학습 강도
                  

                    
                    
                    
                  

                

                
⚖️ 기본 — 학습·과적합 균형 (권장 · lr 3e-4)

                

                  🎓 전문가 설정 (파라미터 직접 조정 · 배우면서)
                  
LoRA rank (r)학습 용량. 클수록 많이 외움(메모리↑). 페르소나엔 8~16 충분
                    

                  
lora_alpha학습 강도. 보통 rank의 2배가 정석
                    

                  
lora_dropout과적합 방지. 데이터 적으면 0, 많으면 0.05~0.1
                    

                  
learning_rate학습 속도. 크면 빨리 배우나 망가지기 쉬움
                    

                  
epochs같은 데이터 반복 횟수. 많으면 외우다 과적합
                    

                  
max_seq_length한 번에 보는 토큰 길이. 길수록 메모리 제곱 증가
                    

                  
lr_scheduler학습률 감소 곡선. cosine이 후반 더 부드러움
                    

                  
양자화 (quant)모델 크기·속도. q4_k_m이 균형 최고
                    

                  
max_steps총 학습 횟수. 0이면 데이터수·epochs로 자동
                    

                

              

              
내 모델 위에 누적 학습 → .gguf 모델
