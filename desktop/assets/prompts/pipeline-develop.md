③단계에서 만든 파일은 `{{SESSION_ROOT}}/site/` 아래에 있습니다.

이 단계의 목표: **③에서 만든 UI를 실제 동작하는 제품으로 완성.** 백엔드 로직, 데이터 흘림, 폼 처리, 상태 관리, 통합, 그리고 **엄격한 자기 검증**.

작업:
1. **로직 추가** — 인터랙션이 동작하게 (폼 제출, 상태 전환, 데이터 표시). 필요하면 별도 JS/TS 파일.
2. **데이터 파이프라인** — 목업 데이터라도 실제 흐름이 보이게 (하드코딩 placeholder → 구조화된 데이터).
3. **엣지 케이스** — 빈 상태, 에러 상태, 로딩 상태 최소한 처리.
4. **자기 검증 (필수)** — 아무리 작아도 반드시 실행:
   - JS/TS: `<run_command>cd {{SESSION_ROOT}}/site && node --check <file></run_command>` 또는 `npx tsc --noEmit`
   - 통과할 때까지 수정 (최대 2회 재시도).
   - 검증 결과를 산출물에 명시.

**설치 금지 해제** — 이 단계에서는 필요하면 `npm install` 가능 (하지만 CDN 기반이면 그대로 유지가 이상적).
