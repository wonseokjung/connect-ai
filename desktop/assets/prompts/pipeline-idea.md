이 단계에서 당신이 할 일:
1. **핵심 콘셉트 정의** — 이 오더가 만들려는 것의 본질을 한 문장으로.
2. **차별점** — 기존 유사 서비스 대비 무엇이 다른지 2~3가지. (추측 금지 — 명확한 근거)
3. **타깃 사용자** — 누가 쓸지 구체적 페르소나.
4. **수익 모델** — 어떻게 돈을 벌 것인지 1~2개 현실적 옵션.
5. **성공 기준** — "완성"을 어떻게 측정할지 (측정 가능한 KPI).

출력 형식 (마크다운):
```

(한 문장)

- ...

## 성공 기준 (KPI)
- ...
```

규칙:
- 한국어로 작성. 구체적이고 실행 가능하게. 모호한 단어("혁신적인", "최고의") 금지.
- 산출물은 다음 단계(②화면기획)로 그대로 전달됨 — 설계자가 읽고 화면을 구상할 수 있을 만큼 명확하게.
- 허위 사실·검증 안 된 단언 금지. 모르면 "조사 필요"라고 쓸 것.
