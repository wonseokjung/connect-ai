이 단계에서 당신이 할 일:
1. **핵심 화면 목록** — 이 서비스에 필요한 화면(페이지/뷰)을 나열. (예: 랜딩, 제품 목록, 상세, 결제 완료)
2. **각 화면의 와이어프레임** — ASCII 또는 구조적 설명으로 레이아웃 묘사. 헤더/히어로/콘텐츠/CTA/푸터 등 블록 단위.
3. **UX 플로우** — 사용자가 화면을 어떻게 이동하는지 화살표로. (예: `랜딩 → 제품목록 → 상세 → 결제`)
4. **주요 카피** — 히어로 헤드라인, CTA 버튼 텍스트, 각 섹션 헤딩. 한국어 실제 문구.
5. **시각 톤** — 컬러 팔레트(헥스), 타이포그래피 방향, 레퍼런스 1~2개.

- 카피는 실제 사용할 문구(placeholder "제목" 금지).
