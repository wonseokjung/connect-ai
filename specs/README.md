# 📋 Connect AI v3 구현 스펙 — 사용 가이드

> 이 폴더의 스펙은 **어떤 AI 모델에게든 그대로 복붙**하면 Fable 5 수준의 결과가 나오도록 설계됨.
> 로컬 모델(Ollama qwen3 등), 코딩 플랜(GLM 등), Claude/GPT 계열 모두 대상.

## 복붙 방법 (반드시 지킬 것)

1. **항상 `SPEC-00-COMMON.md`를 먼저 붙여넣고**, 그 아래에 작업할 SPEC 하나를 이어 붙인다.
   (SPEC-00은 저장소 사실관계 + 금지사항. 이게 빠지면 약한 모델이 멋대로 리팩터링함)
2. **한 번에 SPEC 하나만.** SPEC-01 완료·검증 후 SPEC-02로.
3. 각 SPEC 완료 후 **검증 절차를 통과해야 다음으로 진행**:
   ```bash
   npm run compile        # esbuild 번들 — 에러 0이어야 함
   ```
4. SPEC 순서 (의존 관계):
   ```
   SPEC-01 (llm 코어 모듈)          ← 다른 파일 수정 없음. 가장 안전
      ↓
   SPEC-02 (라우터 + 설정 + 시크릿)  ← package.json 스키마 추가 포함
      ↓
   SPEC-03 (extension.ts 통합)      ← 앵커 기반 최소 수정. 가장 조심
      ↓
   SPEC-04 (UI 라우팅 보드)         ← 웹뷰 확장
   ```

## 실행 모델에게 줄 공통 지시문 (스펙 위에 이 한 줄도 같이 붙이면 좋음)

```
아래 스펙을 그대로 구현하라. 스펙에 없는 파일은 절대 수정하지 말고,
스펙에 있는 코드는 한 글자도 창작하지 말고 그대로 파일에 쓰라.
"개선"이나 "리팩터링"을 제안하지 말고, 모호하면 스펙의 [결정 규칙]을 따르라.
완료 후 npm run compile 을 실행해 에러 0을 확인하고 결과를 보고하라.
```
