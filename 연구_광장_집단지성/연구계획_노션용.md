# 🌐 연구 시리즈 — 멀티에이전트 집단지성 (Connect AI 기반)

> **한 줄 비전:** AI 1인 기업의 에이전트들이 — 서로 다른 사람(조직)의 사적 지식 + 수술로 다양화된 모델을 들고 — 모이면, 혼자보다 문제를 더 잘 푼다.

---

## 🧩 핵심 논제 (Thesis)

> **쓸모있는 에이전트 "다양성"에는 두 개의 축이 있다 — 능력(모델)과 지식(데이터).**
> 우리는 둘 다 **싸게 제조**하고(수술로 능력 / 사적지식으로 지식), **둘이 곱해진다(compound)** 는 걸 보인다.

이 "2축 분해"가 핵심 novelty. 기존 Mixture-of-Agents는 **능력 축 하나만** 다뤘다.

---

## ✅ 파일럿 결과 (이미 검증)

가상의 사적 지식(모델이 모르는 고유 토큰)으로 "지식 축"만 통제 실험:

| 조건 | 정답률 | 의미 |
| --- | --- | --- |
| **SOLO** (혼자, 자기 지식만) | **0 / 4 (0%)** | 혼자선 cross-org 문제를 못 푼다 (parametric 누수 없음 = 깨끗한 격리) |
| **PLAZA** (광장 협력) | **3 / 4 (75%)** | 지식 전이로 대부분 해결 · 지식전이율 75% |

> ⚙️ 모델: gemma-4-E2B (로컬, Connect AI 내장 엔진) · 하니스: `실험_광장_집단지성_harness.py`
> → "협력 없으면 0%, 광장에선 75%" — 핵심 주장이 데이터로 증명됨.

## ⚠️ Novelty 점검 (딥리서치 결과 — 정직하게)

### 이미 나온 것 (이대로 쓰면 reject)

| 우리 주장 | 이미 한 논문 |
| --- | --- |
| 다른 모델이면 더 잘된다 | **Mixture-of-Agents** (arXiv:2406.04692, ICLR'25) — "이종 모델 > 복제" 이미 증명 |
| 역할/추론 다양성 | **Heterogeneous Multi-Agent Debate (A-HMAD)** — 정확도 +4~6%, 사실오류 −30% |
| 에이전트별 다른 RAG/지식 | **CLADD · Internet of Agents (2407.07061) · HedraRAG** |
| abliteration 수술법 | OBLITERATUS = 엔지니어링(Arditi+Gabliteration 조합), 연구 novelty 아님 |

→ "멀티에이전트 + 다양성 = 더 잘됨" 자체는 **2024년에 끝난 얘기**.

### 검색해도 안 나온 빈틈 (= 우리 novelty)

1. ⭐ **다양성을 "수술"로 제조** — 기성 다른 모델을 고르는 게 아니라, **한 베이스 모델을 task vector·steering으로 N개 상보적 전문가로 만들어** 집단지성을 낸다. ("5개 70B 없이, 한 모델 수술로 싸게 다양성")
2. ⭐ **진짜 cross-user · 사적지식 사회** — 기존은 한 시스템 안 or 시뮬. 우리는 **서로 다른 실제 소유자**가 **남이 모르는 사적 지식**을 들고 모임. (능력 다양성이 아니라 **지식 다양성·전이**)
3. ⭐ **온디바이스 · 무료 · 비전문가** — 민주화 각도.

## 📊 통합 실험 설계 — 2×2 Factorial

두 축을 한 실험에서 교차:

|  | **공유 지식** | **사적/분산 지식** |
| --- | --- | --- |
| **같은 모델** (능력 동일) | 베이스라인 | = 우리 파일럿 (0%→75%, 지식 축만) |
| **수술된 모델** (능력 다양) | ≈ MoA (능력 축만) | ⭐ **풀 (둘 다)** → 가설: 최고 |

- **종속변수:** 집단 정답률 · 지식전이율 · 기여조직 다양성 · (선택) 시간
- **결과로 주장:** 각 축이 각각 돕는다 + **둘이 곱해진다** + **MoA 대비 우위** (MoA는 오른쪽 위 칸까지밖에 없음)

## 🚨 윤리 원칙 (안 지키면 desk-reject)

> **abliteration(검열제거)을 "에이전트 다양성 엔진"으로 쓰지 않는다.** "무삭제 모델들의 멀티에이전트"는 publish 불가.
> - 다양성은 **benign 수술**로: task arithmetic · activation steering · 다른 LoRA · 다른 RAG.
> - abliteration은 **해석가능성(refusal direction 이해)까지만** (논문 C). "원리는 이해하되, 위험한 모델 배포는 안 한다."

## 🛣️ 로드맵 (빠른 거 안 늦추게 단계로)

1. **[완료] 지식 축 파일럿** — 사적토큰, SOLO 0% → PLAZA 75%
2. **[다음] 능력 축 수술** — 작은 모델 1개 → task vector/steering으로 전문가 3~4개 → 하니스에 꽂아 **2×2 완성**
3. **[그다음] 스케일업** — 문제 12~20개 × 3 trial → 평균±CI (통계)
4. **[병렬] 워크숍 초안** — Abstract · Method · 2×2 표 · Limitations · Related Work
5. **[Phase 2] 라이브 cross-user 실험** — 채널 모집 · 동의/IRB · 비용안전(limitToLast·시간박스) · 익명 로깅 → 논문 B 본편

> 💡 통제실험(2×2, 시뮬, 빠름) = 논문 한 편. 라이브는 **별도 phase** — 빠른 페이퍼를 여기 묶지 말 것.
